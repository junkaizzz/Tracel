Release notes
=============

v0.1.0
------

First public release.

* OT1: low-rank unbalanced fused Gromov–Wasserstein cell alignment with type-balanced marginals and the
  unbalanced blend; ``use_structure`` switches the cell-group structure term on or off.
* OT2: windowed, gene-wise unbalanced Sinkhorn transcript assignment with the 12 µm hard cut, raw row-mass
  recording and the relative row-mass filter (default 0.1); weighted records for Visium HD.
* ``tracel`` command-line interface and a Slurm example for the Xenium Sample2 dataset.
